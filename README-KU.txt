NINJA TRANSLATE - Android project

ئەم پڕۆژەیە کۆدی index.html ـی تۆ لە ناو ئەپێکی Android WebView دادەنێت.
Package ID: com.ninjatranslate.app
Version: 1.0

گرنگ:
- ئەمە سەرچاوەی پڕۆژەی Android ـە، نەک APK/AAB ئامادە.
- لە ژینگەی ئێستادا Android SDK و Gradle نییە؛ بۆیە نەتوانرا APK/AAB لێرە compile و sign بکرێت.
- پڕۆژەکە لە Android Studio یان AndroidIDE بکەرەوە و پاشان Gradle Sync بکە.
- بۆ APK: Build > Build APK(s)
- بۆ AAB: Build > Generate Signed Bundle / APK > Android App Bundle
- بۆ AAB ـی Google Play پێویستە signing key/keystore ـی تایبەتی خۆت دروست بکەیت و بە پارێزراوی هەڵیبگریت.
- بۆ بەکارهێنانی Google Play، پێویستە زانیاری و ڕێنماییەکانی پۆلیسی Google Play و Data safety پڕ بکرێنەوە.

تێبینی دەنگ:
WebView وەشان و پشتگیری Web Speech لە مۆبایلە جیاوازەکاندا جیاوازە. مایکرۆفۆن permission لەم پڕۆژەیەدا داواکراوە، بەڵام speech recognition/speech synthesis دەبێت لەسەر ئامێری ڕاستەقینە تاقی بکرێتەوە.
